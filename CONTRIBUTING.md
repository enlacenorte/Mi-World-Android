# 🤝 Contributing to GEO ORBIT 3D

We welcome contributions from educators, developers, designers, and open-source enthusiasts!

## How to Contribute

1. **Fork the Repository**:
   Click the **Fork** button on GitHub to create your own copy of `Mi-World-Android`.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-geography-feature
   ```
3. **Make Your Changes**:
   - Keep the codebase lightweight, modular, and performant.
   - Preserve zero-dependency architecture wherever possible.
   - Test responsive touch behavior across mobile viewport widths (320px - 1440px).
4. **Commit Your Changes**:
   ```bash
   git commit -m "Add: Amazing new educational feature"
   ```
5. **Push to Your Branch**:
   ```bash
   git push origin feature/amazing-geography-feature
   ```
6. **Open a Pull Request**:
   Describe your changes and the pedagogical or technical value they bring.
